Nhiệm vụ: $ARGUMENTS

1. Đọc `CLAUDE.md` và code liên quan. Chưa sửa code.
2. Nếu yêu cầu còn mơ hồ, hỏi tôi các câu làm rõ trước.
3. Viết kế hoạch vào `plan.md` theo mẫu có sẵn: mục tiêu và phạm vi (kể cả điều không làm), file bị ảnh hưởng, các bước nhỏ dạng checkbox `- [ ]` (mỗi bước làm xong chạy được, test được, có tiêu chí hoàn thành), rủi ro, câu hỏi còn mở.
4. Dừng lại để tôi review. Không bắt đầu code.
